# AtliQ Hardwares – Providing Insights to Management in Consumer Goods Domain
      This project is a part of Resume Project Challenge by Codebasics.  This is the fourth challenge in the consumer Goods Domain.
###  Problem Statement  
        AtliQ Hardware is a major producer of Hardware components, including personal computers and laptops.  They have a strong presence across various parts of the world.  As their business is expanding, they decided to hire a Junior Data Analyst to provide them with insights and help them with Data-driven decisions.  So, the Data Analytics Director, Tony Sharma decided to conduct a SQL challenge to evaluate both the technical skills and soft skills of the candidate.  Here, each participant is assigned to complete a set of 10 ad_hoc requests and present the insights through a powerpoint presentation.

### Key Learnings
  1. Basic SQL commands
  2. Subqueries, CTE - Common Table Expressions
  3. User-Defined Functions, Window Functions
  4. Views - Temporary Tables, Stored Procedures
  5. Presentation skills
---

###  Tools Used 
- **SQL** → Data Exploration and Analysis 
- **Power BI** → Data Visualisation   
- **PowerPoint** → Presenting Insights to the stakeholders
